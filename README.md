# IBM Bob – India Travel Planner Agent

## Project Overview

IBM Bob – India Travel Planner Agent is an Agentic AI based travel planning solution designed to help users create personalized travel plans across India.

The system understands user requirements such as destination, duration, budget, travel style, and preferences, and generates customized travel recommendations and itineraries.

## Key Features

- Personalized India travel planning
- Agentic AI based task orchestration
- Day-wise itinerary generation
- Budget estimation and breakdown
- Attraction recommendations
- Weather and travel information
- Conversational itinerary modification
- Real-time information retrieval
- Interactive travel assistant

## Role of Agentic AI

Agentic AI enables IBM Bob to understand user intent, coordinate travel-related tools and agents, retrieve relevant information, make planning decisions, and continuously adapt the itinerary according to user requirements.

## Project Output

The system generates personalized travel plans based on user prompts, including destinations, attractions, day-wise schedules, budget estimates, and travel recommendations.

## Project Architecture

The architecture includes the user interface, application layer, IBM watsonx.ai orchestration, specialized travel tools/agents, external travel information services, data storage, security, and personalized output.
